# Calculation timing

New runs only add `calculations.timing = {version: 1, cells: [{index, answerEntryMs, focusedMs, visits, edits}]}`. Outcomes and their immutable cell arrays remain unchanged. Timing cells use the same `(run.id, index)` identity, in row-major order. No historical values are filled in. Both extensions are committed in the existing score intent/lock/replay/receipt transaction; cancellation/reset discards the unsubmitted collector.

`answerEntryMs` is cumulative active focused milliseconds through the final accepted value change, including thinking before the first digit and corrections across revisits. A later visit without editing does not move that checkpoint. A final blank has `null`, never a fabricated zero; an actual same-tick edit can measure zero. `focusedMs` includes all observed active focus, including post-edit waits and unedited revisits. `edits` counts accepted changed strings, including clearing/retyping (not rejected input or unchanged values). `visits` counts focus entries, not environment resumes. Pauses retain the current cell; resuming does not add a visit.

Collection starts at the actual ready-to-running transition with the first cell's intended autofocus. The initiating/held start key is consumed, not an edit. Tab, Shift+Tab, arrows, optional Space advance and mouse movement close/open explicit focus intervals; boundary navigation that keeps focus does not add a visit. Blurring to a control stops cell focus. Active time excludes hidden documents, unfocused windows and non-Practice routes; the existing whole-round elapsed timer is unchanged. Returning to Practice only resumes if a cell actually has focus. Finishing snapshots/stops the collector synchronously before saving: the final-cell wait until Finish contributes to `focusedMs`, not `answerEntryMs`. StrictMode effect replay cannot start a second collector or duplicate intervals.

The Times view ranks ordered operand pairs by descending median **correct-final-answer** entry duration, then numeric operands. Reversed operands stay distinct. Incorrect-final-answer samples remain separately marked and inspectable; blanks have no answer-entry sample. Rows without correct samples show a dash and follow ranked rows. All real samples, including zeros, duplicates and extremes, are retained. The strip plot shows each raw sample against a per-pair seconds scale; exact values/outcomes/run dates are available in a keyboard-accessible disclosure. No percentiles or inferred mental-speed claims. Coverage distinguishes timed runs, measured answers and answered details without timing. Stage-1 detail and older aggregate-only runs are missing timing, not zero.

Malformed or future timing blocks writes under the existing fail-closed storage contract; raw source stays intact and the existing unavailable warning is shown. Unknown fields at every level are preserved. Old cooperating clients preserve unknown extensions when appending; they cannot enrich or replace existing arrays. Web Locks cannot protect against already-open noncooperating old writers.

Design: retain the current slate/yellow Radix palette and typography. Default Errors remains unchanged; a compact Errors/Times inner control switches to a quiet median/sample table with a raw Recharts strip and native disclosure. Both views use all committed history across modes, preset sizes and custom sets, combining identical ordered operands without merging reversed pairs. Stats retains its exact-settings selection. No cohort filter, persistent presentation key or targeted practice mode.
